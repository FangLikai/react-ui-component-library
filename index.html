快速上手

以下将帮助你从零开始搭建一个基于 React Tech UI 的大屏应用。

安装

npm install react-tech-ui

引入样式

在项目入口文件（如 main.tsx 或 App.tsx）中引入组件库样式：

import 'react-tech-ui/dist/style.css';

使用组件

按需引入组件即可使用：

import { ScreenAdapter, TechBorder, DataCard, DigitalNumber } from 'react-tech-ui';

function Dashboard() {
  return (
    <ScreenAdapter width={1920} height={1080} bgStyle="grid">
      <div style={{ padding: 20 }}>
        <TechBorder variant="corner">
          <DataCard title="在线用户" trend="up" trendValue="+12%">
            <DigitalNumber value={12847} fontSize={28} />
          </DataCard>
        </TechBorder>
      </div>
    </ScreenAdapter>
  );
}

export default Dashboard;

大屏适配

使用 ScreenAdapter 组件作为最外层容器，它会根据设计稿尺寸自动缩放内容：

<ScreenAdapter width={1920} height={1080} mode="scale" bgStyle="grid">
  {/* 你的大屏内容 */}
</ScreenAdapter>

ScreenAdapter 大屏适配器

将内容按设计稿尺寸等比缩放，适配不同分辨率的大屏显示。是构建大屏应用的顶层容器组件。

基础用法

<ScreenAdapter width={1920} height={1080}>
  <div>你的大屏内容</div>
</ScreenAdapter>

适配模式

scale — 等比缩放（默认）
<ScreenAdapter width={1920} height={1080} mode="scale">{children}</ScreenAdapter>
width-scale — 按宽度缩放
<ScreenAdapter width={1920} height={1080} mode="width-scale">{children}</ScreenAdapter>
full — 全屏填充
<ScreenAdapter width={1920} height={1080} mode="full">{children}</ScreenAdapter>

背景样式

<ScreenAdapter bgStyle="dark">      {/* 纯深色背景 */}
<ScreenAdapter bgStyle="grid">      {/* 网格背景 */}
<ScreenAdapter bgStyle="particles"> {/* 粒子背景 */}

API

属性说明类型默认值
width设计稿宽度number1920
height设计稿高度number1080
mode适配模式'scale' | 'width-scale' | 'full''scale'
bgStyle背景样式'dark' | 'grid' | 'particles''dark'
className自定义类名string-
style自定义样式CSSProperties-

主题切换容器组件，支持动态切换预设主题和自定义主题，所有子组件自动响应主题变化。

代码演示

基础用法

import { ThemeProvider } from 'react-tech-ui';

<ThemeProvider theme="dark">
  <App />
</ThemeProvider>

预设主题

<ThemeProvider theme="dark">   {/* 深色科技风 */}
<ThemeProvider theme="blue">   {/* 蓝色科技风 */}
<ThemeProvider theme="green">  {/* 绿色科技风 */}
<ThemeProvider theme="purple"> {/* 紫色科技风 */}

自定义主题

<ThemeProvider theme={{
  '--tech-primary': '#ff6b35',
  '--tech-bg-dark': '#1a0a00',
}}>
  <App />
</ThemeProvider>

API

属性说明类型默认值
theme主题名称或自定义变量对象string | Record'dark'
children子内容ReactNode-

FloatingButton 悬浮按钮

科技风格悬浮操作按钮（FAB），支持固定定位和可拖拽模式。内置脉冲动画、四角装饰和四种视觉变体，完美适配主题切换。

代码演示

基础用法

import { FloatingButton, Icon } from 'react-tech-ui';

<FloatingButton
  icon={<Icon name="plus" size={20} />}
  onClick={() => console.log('clicked')}
/>

可拖拽悬浮按钮

<FloatingButton
  icon={<Icon name="settings" size={20} />}
  draggable
  edgeSnap
  variant="neon"
  size={52}
  onClick={() => console.log('clicked')}
  onDragEnd={(pos) => console.log('拖拽结束', pos)}
/>

视觉变体

<FloatingButton variant="default" icon={...} />
<FloatingButton variant="neon" icon={...} />
<FloatingButton variant="glow" icon={...} />
<FloatingButton variant="glass" icon={...} />

带文字标签

<FloatingButton
  icon={<Icon name="message" size={18} />}
  size={56}
  variant="glow"
  draggable
  edgeSnap
>
  消息
</FloatingButton>

命令式调用（方法触发）

支持通过静态方法直接调用，无需在 JSX 中声明组件。默认在右侧显示，支持自定义样式和位置。

import { FloatingButton, Icon } from 'react-tech-ui';

// 显示悬浮按钮（右侧出现，可拖拽）
FloatingButton.show({
  icon: <Icon name="setting" size={20} />,
  children: '设置',
  variant: 'neon',
  draggable: true,
  position: 'right',  // 'left' | 'right' | { x, y }
  onClick: () => {
    FloatingButton.hide();
  },
});

// 更新按钮配置
FloatingButton.update({
  icon: <Icon name="refresh" size={20} />,
  variant: 'glow',
});

// 隐藏按钮
FloatingButton.hide();
